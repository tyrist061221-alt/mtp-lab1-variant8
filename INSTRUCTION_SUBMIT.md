# Как отправить работу на проверку

1. Распакуйте архив, замените ФИО и группу в README.md, закоммитьте:
   `git commit -am "docs: fill in student name and group"`
2. Создайте на GitHub два пустых репозитория: `mtp-lab1-libmath` и `mtp-lab1-variant8`.
3. Запушите подмодуль, затем основной проект:
   `git push --all && git push --tags`
4. Отправьте боту ссылку на репозиторий `https://github.com/USERNAME/mtp-lab1-variant8`
   отдельным сообщением.
5. Дождитесь вердикта (1–3 минуты).
